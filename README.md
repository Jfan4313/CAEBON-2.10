# 园区综合能源项目投资收益测算与辅助决策系统 V2.14

> 简称：零碳项目辅助决策系统

本项目是基于 Electron、React、TypeScript 和 Vite 的桌面测算软件，用于园区综合能源项目的数据管理、改造方案分析、财务测算、方案比较与报告输出。

## V2.14 正式范围

- 项目基础信息、建筑、设备、用能与电费账单录入
- 电价模型配置
- 分布式光伏投资收益测算
- 储能套利、容量分析及光储协同优化
- 已稳定的空调、照明、热水和充电桩改造测算
- 综合投资、收益、节能、减碳、IRR、NPV、现金流和投资回收期分析
- EPC、EMC 等投资模式，方案比较与敏感性分析
- 本地项目保存、历史记录与用户偏好记忆
- 已稳定的 Excel 和 PDF 报告输出

## 不纳入 V2.14 申报范围

以下能力属于实验、预研或后续计划，不作为 V2.14 已完成功能申报：真实 AI 模型自动决策、真实碳交易、虚拟电厂实时调度、物联网设备实时控制、完整数字孪生控制、实时微电网硬件接入，以及尚未完成的云端多人协同。

## 技术架构

- 桌面端：Electron 40
- 前端：React 19 + TypeScript 5.8 + Vite 6
- 图表：Recharts
- 本地存储：IndexedDB / localStorage
- 可选服务：Supabase（不纳入 V2.14 申报功能）

业务代码按领域组织在 `modules/` 下；跨模块基础能力位于 `shared/`，外部服务封装位于 `services/`。详细开发规范见 `AGENTS.md`。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run electron:build
```

生成物位于 `dist/` 与 `dist-electron/`，不得纳入软著自主源程序鉴别材料。
