# AI辅助开发与人工贡献说明

本软件研发过程中可能使用生成式 AI 辅助需求梳理、代码建议、文档草拟、测试用例设计和排版。AI 工具不作为作者或权利主体。软件形成受人的实质控制，建议保留以下证据：

1. 人提出的业务目标、输入参数、约束和验收标准；
2. 人对候选实现的选择、否决、修改与集成记录；
3. Git提交、代码审查、缺陷修复和模块重构记录；
4. 光伏、储能、IRR、NPV、回收期、现金流等标准算例与独立公式复核；
5. 人对功能范围、未完成功能、权属边界和申报材料的最终确认。

本轮整改中的实质人工控制体现为：依据现有代码核对功能，隐藏不实入口；统一产品身份；建立匿名标准算例；对代码输出进行独立 Excel 公式复核；逐表渲染检查；对权属事实保持待确认而不自动推断。

AI预研页面、模拟收益和未接入真实模型的功能不作为“AI真实自动决策”申报。核心算法仍需由项目负责人或具备相应专业能力的人员签字复核。
