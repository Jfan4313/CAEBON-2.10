# 临时与废弃文件处置清单

| 路径/类别 | 结论 | 处理方式 |
|---|---|---|
| `outputs/` | 历史表格、预览图及临时构建脚本 | 不删除用户文件；已忽略；申报归档排除 |
| `tmp/` | 本轮文档、表格与PDF视觉校验中间产物 | 已忽略；申报归档排除 |
| `dist/`、`dist-electron/` | 自动构建产物 | 仅安装包单独归档；自主源程序排除 |
| `node_modules/` | 第三方依赖代码 | 自主源程序与源码归档排除 |
| `electron/main 2.js` | 与 `electron/main.cjs` 重复的历史文件 | 不作为正式入口；冻结提交前建议停止跟踪，源程序排除 |
| `fix_divs.py`、`test.py`、`test_rc.py`、`track_divs.py`、`fix_project_entry.js` | 含历史个人绝对路径的一次性修复/检查脚本 | 保留历史证据，不进入正式源码归档 |
| `algorithms/*.js`、AI算法HTML | AI预研/生成材料，与V2.14正式范围不一致 | 不进入V2.14自主源程序 |
| `.DS_Store`、日志、预览PNG | 系统或检查输出 | 排除 |
| `public/solar-construction/*` | 光伏施工参考图 | 需确认图片来源/授权；未确认前不进入自主源程序和申报截图 |

本轮不使用破坏性命令清除用户现有文件；所有排除通过忽略规则、选择清单和归档白名单完成。
