# 开源许可与第三方依赖核查

## 自有代码许可状态

仓库 README 和旧构建说明曾直接写有“MIT License”，但仓库根目录未见独立 `LICENSE` 文件。仅凭 README 历史表述无法判断仓库是否曾公开、何时公开、公开范围及是否构成对自有代码的有效 MIT 授权。本轮已移除面向当前 V2.14 的直接 MIT 声明，并保留“授权状态待权利人书面确认”的事实说明；不得改写既有 Git 历史。

远端地址为 GitHub 仓库 `Jfan4313/CAEBON-2.10`。仓库当前或历史可见性需由账号持有人在 GitHub 设置及事件记录中核实，不能由本地仓库推断。
