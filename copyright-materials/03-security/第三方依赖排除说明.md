# 第三方依赖排除说明

V2.14 自主源程序材料仅选择项目团队编写的业务代码。下列内容明确排除：

- `node_modules/` 中全部第三方包；
- React、React DOM、Electron、Vite、TypeScript、Recharts、Supabase SDK、Axios、idb、jsPDF、html2canvas、html2pdf.js、xlsx、pigeon-maps 等依赖实现；
- `dist/`、`dist-electron/` 中经过打包、压缩、合并或转译的自动生成代码；
- 浏览器/CDN加载的 Tailwind CSS、Google Fonts、Material Icons；
- 第三方图片、图标、字体、模板与未确认授权的视觉资产；
- 自动生成的锁文件、测试输出、预览图和安装包内部第三方代码。

源程序鉴别材料优先选择应用入口、项目模型、光伏、储能、财务、项目存储、用户偏好和报告编排等第一方 TypeScript/TSX 文件，并在选择清单中逐项标明。
