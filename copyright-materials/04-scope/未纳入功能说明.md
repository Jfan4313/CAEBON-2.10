# V2.14 未纳入功能说明

以下功能不作为 V2.14 已完成能力申报，也不得在申请表、用户说明书和设计说明书中描述为可用生产功能：

| 功能 | 当前性质 | V2.14 处理 |
|---|---|---|
| 真实 AI 模型自动决策 | 演示/模拟计算，未接入可核验真实模型闭环 | 入口隐藏，源程序材料排除 |
| 真实碳交易市场交易 | 分析/预研页面，未接入真实交易与结算 | 入口隐藏，说明书排除 |
| 省级虚拟电厂实时调度 | 仿真/预研，不具备省级平台实时接口与调度资质 | 入口隐藏，说明书排除 |
| 物联网设备实时控制 | 未完成真实设备接入、鉴权和控制闭环 | 不纳入 |
| 完整数字孪生控制系统 | 可视化/仿真不等同于生产数字孪生控制 | 不纳入 |
| 实时微电网硬件接入 | 当前以模拟、手工参数和可视化为主 | 仅可描述离线分析，不描述实时控制 |
| 云端多人协同 | Supabase 为可选适配，尚未形成稳定多人协同闭环 | V2.14 入口隐藏 |

微电网页面如用于演示，只能表述为“离线场景可视化与测算辅助”，不得声称已连接现场设备或执行实时调度。
