# 开发完成与首次发表日期说明

## 开发完成日期

当前状态为“V2.14申报冻结候选版”，尚未满足全部冻结条件，因此暂不填写最终开发完成日期。建议以以下事件全部完成的实际日期作为依据：

1. 权属链书面确认；
2. 核心算例和人工专业复核完成；
3. 生产构建、安装包、报告导出和存储回归通过；
4. 用户说明书、设计说明书、截图和源程序材料与软件一致；
5. 创建最终提交及 `copyright-v2.14` 标签。

## 首次发表日期

本地 Git 记录、远端地址和 README 不能单独证明软件已向公众发表。以下事实待用户确认：是否曾公开GitHub仓库、公开上线、向客户交付、公开演示、发布安装包或以单位名义正式使用。

- 若从未向公众提供：按真实情况记录“未发表”。
- 若已发表：使用可核验的最早公开日期，并保存网页快照、发布记录、交付/演示凭证或其他证据。
- 不以未来计划、内部提交日期或倒填日期替代首次发表事实。
